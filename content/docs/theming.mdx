Every component is styled with CSS variables, so changing the look of the whole library means changing a few
values in your global stylesheet.

## Tokens

| Token                                                            | Used for                                                    |
| ---------------------------------------------------------------- | ----------------------------------------------------------- |
| `--primary` / `--primary-foreground`                             | Primary buttons, links, active states                       |
| `--primary-text`                                                 | Primary-colored text on light surfaces                      |
| `--secondary` / `--secondary-foreground`                         | Secondary buttons and badges                                |
| `--accent` / `--accent-foreground`                               | Hover and selected states                                   |
| `--destructive` / `--destructive-text`                           | Errors and dangerous actions                                |
| `--success`, `--warning`, `--info` (+ `-foreground`, `-text`)    | Status colors                                               |
| `--background`, `--foreground`, `--card`, `--popover`, `--muted` | Surfaces and text                                           |
| `--border`, `--input`, `--ring`                                  | Borders, inputs and focus rings                             |
| `--radius`                                                       | Base corner radius; smaller and larger radii derive from it |

Light values live in `:root` and dark values in `.dark`.

## Dark mode

Components switch when an ancestor has the `dark` class. With Next.js, [next-themes](https://github.com/pacocoursey/next-themes)
manages that class for you, and the [Theme Changer](/docs/components/theme-changer) component toggles it.

## Your own theme

Open the [Themes](/themes) page, pick a preset or set your own colors for each mode, and copy the generated
CSS to the end of your `globals.css`. It only overrides the tokens you changed. Foreground colors are chosen
for contrast automatically, and text shades are mixed from the base color.
